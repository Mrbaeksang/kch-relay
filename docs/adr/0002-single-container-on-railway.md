# Go·React·SQLite를 단일 컨테이너로 배포한다

약 100명 규모의 사내 마켓에서 무료 인프라 이용료뿐 아니라 개발 시간과 운영 부담을 줄이기 위해, Cloudflare 분산 서비스 대신 모노레포의 Vite·React 화면과 Go API를 단일 Docker 이미지로 묶는다. Go가 정적 파일을 제공하고 Railway 서비스 하나에서 실행하며 SQLite·사진은 영구 볼륨에 저장한다. 별도 Node·DB·S3 서버를 운영하지 않는 대신 단일 인스턴스와 재배포 시 잠깐의 중단을 수용하고, 운영 개시 전 일관된 DB·사진 백업과 복원을 마련한다.
