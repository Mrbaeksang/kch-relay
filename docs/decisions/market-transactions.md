# 기능 3 · 상품 관리와 거래 처리 결정 기록

작성일: 2026-11-11. 이슈 #18. PRD에서 **제안** 또는 미정으로 남은 항목 가운데 구현에 필요한 것을 아래와 같이 정했다. 팀이 다르게 확정하면 이 문서와 코드를 함께 바꾼다. 다른 화면은 이 정책을 추론하지 않고 API의 `canApply`·`status`·`actions`를 사용한다.

## PRD 제안을 채택한 항목

| 항목 | 결정 | 근거 |
|---|---|---|
| 진행 중 거래 제한 | 같은 상품·같은 구매자의 REQUESTED·ACCEPTED 거래는 한 건. 위반 시 409 `ACTIVE_DEAL_EXISTS`(details.dealId) | PRD 5장 제안. 미정 정책이므로 DB 고유 제약 대신 신청 트랜잭션 안에서 검사한다 |
| 재신청 별칭 | 철회·거절·완료 후 재신청은 새 거래이며 상품 내 별칭(익명 N)과 대화(conversationId)를 유지한다. 번호는 재사용하지 않는다 | PRD 7장 제안, 공통 EnsureParticipantTx 동작 |
| 신청·수정 수량 상한 | 새 신청과 신청 수량 수정은 현재 잔여 수량 이하. 대기 신청들의 합계는 잔여 수량을 넘을 수 있다 | PRD 4장 제안 |
| 신원 공개 유지 | 한 번 수락된 두 사람은 같은 상품의 이후 재신청에서도 신원이 보인다(participants.identity_revealed_at 기준) | PRD 7장 제안 |
| 반복 요청 | 이미 목표 상태인 철회·거절·수락·완료 요청은 현재 결과를 200으로 반환하고 재고 차감·알림을 반복하지 않는다. 다른 불가능 상태는 409 `INVALID_STATE` | API 명세 4장 |

## 새로 정한 항목

- **숨김 시 대기 신청**: 상품을 숨기면 대기 신청을 모두 거절하고 신청자마다 거절 알림을 같은 트랜잭션에서 만든다. 숨김 상품의 대기 신청은 수락할 수 없어 남겨 둘 이유가 없기 때문이다. 성사된 거래의 완료 처리는 숨김 뒤에도 할 수 있고, 거래·쪽지 기록은 그대로 남는다. 숨긴 상품은 더 이상 수정·수량 변경·모집 변경을 받지 않는다(409).
- **권한 오류**: 남의 상품 관리 요청과 당사자가 아닌 사람의 거래 요청은 404로 응답해 ID만으로 존재를 알 수 없게 한다. 거래 당사자가 상대의 역할 동작(구매자의 수락, 판매자의 철회 등)을 요청하면 403이다.
- **멱등키**: 진행 중 거래 한 건 제한이 같은 신청의 중복 생성을 막으므로 이 기능에서는 `Idempotency-Key` 저장소를 만들지 않는다.

## 입력 상한

| 값 | 상한 |
|---|---|
| 제목 | 앞뒤 공백 제거 후 1~100자 |
| 내용 | 앞뒤 공백 제거 후 1~5,000자 |
| 단가 | 0~10,000,000,000원(PRD 최소 1억 원 지원 조건 충족) |
| 잔여·신청 수량 | 잔여 0~10,000, 신청 1~10,000 |

단가×수량의 최대값 10^14는 JavaScript 안전 정수 범위(2^53−1, 약 9×10^15) 안이다. 상품 등록(#17)의 product 상수를 그대로 참조한다. 모든 화면은 /product-limits와 같은 한도를 따른다.

## 다른 기능과의 연결

- **사진(#17)**: 상품 수정의 사진 교체는 `AttachImagesTx` 계약(같은 tx·상품ID·판매자ID·imageIds, 자체 commit 없음)을 `transactions.Module`에 주입해 사용한다. 운영 서버에서 실제 product.AttachImagesTx를 연결했으며 사진 추가·제거를 내용 저장과 함께 처리한다.
- **장터 조회(#16)**: `transactions.CanApply`로 canApply를 계산할 수 있다.
- **쪽지(#19)**: 거래의 `conversationId`는 participants.id이며 전역 사용자 ID를 포함하지 않는다.
- **알림(#20)**: 거절·수정 일괄 거절·숨김 거절 모두 공통 `AppendRejectionNotificationTx`를 같은 트랜잭션에서 호출한다.
- **통계(#21)**: 완료 처리는 completed_at과 확정 단가·수량만 기록한다.
