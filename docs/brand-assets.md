# KCH 공식 에셋과 사내 장터 이름 후보

## 공식 기준

사용자가 제공한 `KCH Group CI Guidelines(Outlined)_250227.pdf`에서 로고·서체·색상·금지 사례 규정 6쪽을 발췌해 `docs/brand/kch-ci-guidelines.pdf`에 보관한다. 명함·봉투 등 연락처가 포함될 수 있는 적용 예시는 저장소에 복사하지 않는다. 원본 전체는 사용자 제공 파일이며, 원본과 발췌본 해시를 구분한다. 아래 쪽수는 원본 기준이고 발췌본은 원본3·17·18·19·20·21쪽 순서다. CI는 이 PDF를 우선하며 앱 UI 규약은 루트 DESIGN.md를 따른다. 확인일 2026-11-11. SHA-256과 추출 근거는 frontend/public/brand/kch/source.json에 기록했다.

## 웹용 로고

권장 경로는 `/brand/kch/kch-logo.svg`다. PDF 3쪽의 메인 로고를 구성하는 네 개의 벡터 경로를 그대로 추출하고 웹 색상은 PDF 20쪽에 명시된 HEX로 적용했다. 글자 재작성·추측한 심볼·래스터 확대를 사용하지 않았다. 메인 로고와 서비스 이름 Relay는 별도 요소다.

이전 `/brand/kch/kch-logo-official.svg`는 공식 사이트 준비중 페이지에서 확보한 단색 원본으로 출처 보존용이다. 현재 화면에는 사용하지 않는다. 앞서 기록한 웹 사이트 https://www.kchglobal.com/?p=15 의 이전 CI 다운로드는 당시503으로 실패했으며, 사용자 제공 PDF로 기준을 보완했다.

- 원본 도형·비율·색상을 보존하고 재색칠·CSS필터·그라데이션·임의 반전을 하지 않는다.
- 상품 사진·익명 사용자 아바타의 대체 이미지로 사용하지 않는다.
- 최소3mm는 인쇄 규정이다. 임의의 웹 최소px 규정으로 재해석하지 않고 앱 표시 너비72px와 여백을 유지한다.
- 임의로 조합한 장터 이름을 공식 그룹 CI라고 표시하지 않는다.
- KCH 브랜드 자산이며 프로젝트 코드의 오픈소스 라이선스로 재허가하지 않는다.

## 웹 서체

Pretendard Variable v1.3.9를 공식 배포 저장소에서 확보했다. frontend/public/fonts/pretendard에 WOFF2(약2MiB)·SIL OFL 라이선스·출처와 해시를 보관한다. 하나의 자체 호스팅 파일과 font-display: swap을 사용하며 외부 CDN·추가 서버는 없다. 시스템 글꼴 fallback을 유지한다. Gotham 파일이나 사용권은 제공되지 않았으므로 배포하지 않는다.

## 앱 디자인

공식 Ocean Blue를 주요 버튼·링크·포커스에 사용하고, 흰 배경·진한 본문·사진과 가격 중심 목록으로 구성한다. Sky Blue와 Gray를 작은 글자의 색으로 쓰거나 흰 글자를 그 위에 놓아 대비를 낮추지 않는다. 상태색과 밝은 보조 배경은 별도의 앱 토큰이며 그룹 공식 CI 색상이 아니다. 상세는 DESIGN.md와 개발 전용 /design-system을 따른다.
