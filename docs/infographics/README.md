# 사내 마켓 인포그래픽

2026-11-04 기준 PRD·ERD·API 명세 초안을 비개발자용으로 요약한 4장이다. 청록색은 확정 정책, 주황색 점선은 미확정 설계 제안을 나타낸다. 세부 규칙은 원문 문서를 우선한다.

| 이미지 | 설명 | 원문 |
|---|---|---|
| [01 서비스 흐름](01-service-flow.png) | 가입·상품 등록·인사팀 승인·신청·수락·완료 | [PRD](../prd.md) |
| [02 핵심 규칙](02-rules-and-privacy.png) | 익명 공개 시점, 수량 차감, 상품 수정과 거래 합의값 | [PRD](../prd.md) |
| [03 정보 연결 구조](03-information-map.png) | 사원·상품·상품별 익명 연결·쪽지·신청/거래·알림 | [ERD](../erd.md) |
| [04 화면과 서버](04-api-actions.png) | 버튼을 누른 후 서버의 처리와 화면 변화, 쪽지 갱신 | [API 명세](../api-spec.md) |

생성 방식: 내장 image_gen. 배경 투명도 false. [전체 생성 프롬프트](prompts.json).

이미지 제작 시점의 제안 표시와 이후 확정된 정책의 차이는 아래 후속 결정을 따른다. 가입 enum·회사 도메인·퇴사자 세션 회수 등 미정인 세부 구현은 이미지에서 생략했다.

## 후속 결정

이미지 생성 후 사용자가 수량 변경 시 신청 거절 없이 처리하는 정책과 앱 내 알림함을 승인했다. 이미지에 ‘제안’으로 남은 해당 두 항목은 이제 확정 사항이다. 인사팀 기간별 거래 완료 금액 조회와 최소 운영비 제약도 추가되었으며 이미지는 이 추가 내용을 포함하지 않는다. 최신 PRD·ERD·API·기술 스택 문서를 우선한다.
